# Telegram-бот «Массаж Краснодар»

Бот на Python и aiogram 3 с модульной архитектурой. Каждая функция находится в отдельном файле внутри `modules/`, а общий загрузчик автоматически подключает модули при запуске.

## Структура

- `main.py` — запуск бота, приветствие и главное меню.
- `config.py` — настройки через переменные окружения.
- `core/loader.py` — автоматическое обнаружение и подключение модулей.
- `modules/` — отдельные функциональные модули.
- `settings.json` — приветственное сообщение и необязательная картинка.
- `massages.json` — услуги, описания, длительность и цены.
- `certificates.json` — информация о сертификатах.
- `salon.json` — адрес, график, карта, телефон и ссылка на канал.
- `faqs.json` — частые вопросы и ответы.

## Модули

- `services.py` — список и карточки услуг.
- `booking.py` — сбор имени и контакта, отправка заявки владельцу.
- `certificates.py` — подарочные сертификаты.
- `salon.py` — адрес и график.
- `faq.py` — частые вопросы.
- `benefits.py` — польза массажа.
- `channel.py` — переход в Telegram-канал.

## Запуск

Требуется Python 3.10 или новее.

```bash
pip install -r requirements.txt
```

Задайте переменные окружения `BOT_TOKEN` и `ADMIN_ID` (числовой Telegram ID владельца).

Linux/macOS:

```bash
export BOT_TOKEN="ТОКЕН_БОТА"
export ADMIN_ID="ВАШ_TELEGRAM_ID"
python main.py
```

Windows PowerShell:

```powershell
$env:BOT_TOKEN="ТОКЕН_БОТА"
$env:ADMIN_ID="ВАШ_TELEGRAM_ID"
python main.py
```

Для Bothost укажите эти переменные в настройках проекта и команду запуска `python main.py`.

## Добавление нового модуля

Создайте Python-файл в `modules/`, объявите необязательный `order`, список `MENU_ITEMS` и асинхронную функцию `setup(bot, dp)`. Загрузчик автоматически найдёт модуль при следующем запуске.

## Важно

- Заявки отправляются владельцу в личные сообщения. База данных и сбор статистики запусков не используются.
- Дата и время визита не запрашиваются: мастер согласовывает их с клиентом вручную.
- Не храните токен в исходниках или JSON. Используйте переменные окружения/секреты хостинга.
- Перед публикацией проверьте актуальность описаний, цен, адреса, графика и FAQ в JSON-файлах.
