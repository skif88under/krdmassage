# Telegram-бот массажного салона

Бот на Python + aiogram 3. Услуги, цены, сертификаты, адрес, график, ссылка на канал и FAQ редактируются в JSON-файлах в корне проекта рядом с `bot.py`.

## Возможности

- Главное меню: виды массажа, сертификаты, заявка, адрес и график, частые вопросы, канал.
- Карточка услуги: описание, длительность, цена за сеанс и цена курса.
- Заявка: выбор услуги, имя и контакт клиента.
- Уведомление о заявке отправляется в личные сообщения владельцу бота.
- Выбор даты и времени не запрашивается.

## 1. Подготовка Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой числовой Telegram ID через надёжного ID-бота или другой доступный способ.
3. Откройте созданного бота и нажмите **Start** хотя бы один раз, чтобы он мог отправлять вам личные сообщения.

## 2. Локальный запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
```

Linux/macOS:
```bash
source .venv/bin/activate
```

Windows:
```powershell
.venv\Scripts\Activate.ps1
```

Установите зависимости:
```bash
pip install -r requirements.txt
```

Установите переменные окружения перед запуском.

Linux/macOS:
```bash
export BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER"
export ADMIN_ID="ВАШ_ЧИСЛОВОЙ_TELEGRAM_ID"
python bot.py
```

Windows PowerShell:
```powershell
$env:BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER"
$env:ADMIN_ID="ВАШ_ЧИСЛОВОЙ_TELEGRAM_ID"
python bot.py
```

## 3. Настройка контента

Измените JSON-файлы в корне проекта рядом с `bot.py`:

- `massages.json` — услуги, описания, длительность, цена сеанса, цена курса, флаг `active`.
- `certificates.json` — текст и условия подарочных сертификатов.
- `salon.json` — название, адрес, график, карта, телефон, ссылка на канал.
- `faqs.json` — вопросы и ответы.

Для отключения услуги установите `"active": false`. Сохраняйте JSON в UTF-8 и соблюдайте синтаксис JSON.

Цены в примере демонстрационные — замените их на реальные до публикации.

## 4. GitHub и Bothost

1. Создайте репозиторий GitHub и загрузите файлы проекта.
2. Не добавляйте токен в исходники или JSON. Задайте `BOT_TOKEN` и `ADMIN_ID` в переменных окружения/секретах в настройках запуска Bothost.
3. Укажите команду запуска `python bot.py` и установите зависимости из `requirements.txt`.
4. Убедитесь, что все четыре JSON-файла лежат в корне репозитория рядом с `bot.py` и попали в последний коммит. Используйте режим постоянного процесса/worker, если он доступен в тарифе Bothost. Для polling нельзя одновременно запускать несколько экземпляров одного бота.

Названия пунктов панели Bothost могут отличаться. Проверьте, что платформа поддерживает постоянный Python-процесс и исходящие HTTPS-запросы к Telegram API.

## Важно

- Сначала замените демонстрационные услуги, цены, адрес, график, FAQ и ссылку на канал.
- Для первой версии база данных не требуется: заявки сразу отправляются администратору и не сохраняются в боте.
- Если Telegram не позволяет боту написать владельцу, откройте бота и нажмите Start, проверьте `ADMIN_ID` и логи запуска.
